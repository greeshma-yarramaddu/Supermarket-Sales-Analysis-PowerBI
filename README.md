# Supermarket Sales Analysis using Power BI

## Project Overview

This project was developed as part of my Data Analytics training. 
The project uses Power BI to analyze supermarket sales data and create interactive dashboards.

## Skills & Tools Used

- Power BI
- DAX
- SQL
- Excel
- Data Visualization
- Data Analysis

## Dashboard Pages

1. Executive Overview
2. Sales Analysis
3. Product Analysis
4. Branch Analysis
5. Customer Analysis
6. Profit Analysis

## Key Analysis

The dashboard analyzes:

- Overall sales and profit
- Sales trends
- Product performance
- Store/branch performance
- Customer characteristics
- Profitability across categories and stores

## Project Files

The repository contains the Power BI project, dataset, presentation, and supporting project files.

## Note

This project was created for academic/training purposes using a synthetic supermarket sales dataset.
